# Calendar

A customizable calendar application built with Python and Flet.

The project focuses on flexible calendar management, event organization, and an extensible architecture that can support additional tools and integrations.

## Features

- **Calendar generation** — create and manage calendar structures.
- **Event management** — organize events with custom names and colors.
- **Calendar visualization** — view events in a monthly calendar.
- **Daily timeline** — display events along a 24-hour timeline.
- **Custom UI components** — reusable interface elements built with Flet.
- **JSON storage** — store calendar data locally.

## Project Structure

The application is organized into separate modules for data processing, interface rendering, and shared utilities.

```text
calendar/
├── api/
├── ui/
├── data/
├── main.py
└── tools.py
```
